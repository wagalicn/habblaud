# Habblaud 宣传视频 · 制作任务清单（Tasklist）

> 配套文件：[宣传视频脚本与设计.md](宣传视频脚本与设计.md)（下文简称“脚本”）。
> 每个任务写了：**交给谁 / 输入 / 输出 / 验收标准**。模型推荐按 2026 年 11 月的情况，以你手上实际可用的为准。
> 原则：**产品画面一律真录屏**，AI 只做配音、配乐、插画、片头动画和文案。

---

## 分工总览

| 角色 | 推荐 | 主要负责 |
|---|---|---|
| 🧠 总控 / 文案 | Claude 或 DeepSeek（对话模型） | 拆旁白、写字幕 SRT、标题简介、检查事实红线、最后审片 |
| 🎨 生图 | **GPT（GPT Image）** | 封面、片头片尾插画、转场贴图、像素图标 |
| 🎬 有声短视频 | **Grok（Grok Imagine Video）** | 片头 3–5 秒、片尾 GitHub/三连动画（带音效） |
| 🎞 备选视频模型 | Wan 3.0 / Seedance 2.5 / 可灵 | Grok 效果不满意时的替补（图生视频） |
| 🎙 配音 | Qwen-Audio-3.0-TTS-Plus（阿里云百炼）；本地免费：Qwen3-TTS / CosyVoice 3.0 | 中文旁白 |
| 🎵 配乐 | Suno v5（纯音乐，付费档才可商用） | 8-bit BGM |
| 🔊 音效 | 免费音效库（Freesound、爱给网） 或 ElevenLabs Sound Effects | 走路、气泡、叮、金币 |
| 🙋 人工（你） | — | 录屏、截图、打码、剪辑合成、发布 |
| 🤖 DSH（我） | 本机操作 | 准备演示环境、截图、发 Release、写中文安装说明 |

> 视频模型会把像素画糊掉、乱改界面，所以只用它做**插画性质**的片头片尾，不碰产品画面。

  - 建一个演示项目 `D:\demo-todo`；准备好让 DSH 跑的演示任务（写待办 App、跑测试、派一个子智能体、触发一次审批）

- [ ] **T0.3 定配音和 BGM 风格样本** — 🎙 + 🎵
  - 各出 2–3 个 15 秒样本，你选一个定调

## 阶段 1 · 文案（🧠 总控）

- [ ] **T1.1 定稿旁白** — 从脚本第 3、4 节抽出纯旁白，按镜头编号，标注停顿
  - 输出：`narration_main.txt`、`narration_short.txt`
- [ ] **T1.2 写字幕 SRT** — 按建议时间码先出一版，配音完成后再对齐（T3.3）
- [ ] **T1.3 发布文案** — B 站标题 3 选 1、简介、标签、置顶评论；GitHub Release 文案
- [ ] **T1.4 事实核查** — 对照脚本第 0 节“事实红线”逐条检查所有文案
  - 验收：有原作者署名，没写“官方支持”，没提 World

## 阶段 2 · 素材（可并行）

### 2A 真录屏 — 🙋 你（🤖 DSH 可协助截图、调设置）
- [ ] **T2A.1 大场面**：演示模式 `http://127.0.0.1:4747/?mock=1&sessions=8&speed=2` 录夜景楼、摸鱼串门（R1、R13）
- [ ] **T2A.2 中文界面**：语言切换、顶栏、详情、Feed、设置、启动日志（R5–R7）
- [ ] **T2A.3 DSH 实况**：新会话入场、工具气泡、子智能体、等你批准（R2、R3、R8、R9）
- [ ] **T2A.4 交互**：对话窗口发图片、Ctrl+Shift+H 收起、余额卡片和悬停详情（R10–R12）
- [ ] **T2A.5 分屏素材**：DSH 窗口和 Habblaud 同时录（R4）
- [ ] **T2A.6 截图 6 张**（PNG 原尺寸）：全景、中文设置、DSH 小人、余额卡片、对话窗口、子智能体
  - 规格：OBS 1920×1080 60fps；像素画放大用最近邻（`ffmpeg -vf scale=iw*2:ih*2:flags=neighbor`）
  - 验收：每段比脚本时长多录 50%，方便挑

### 2B 生图 — 🎨 GPT
- [ ] **T2B.1 封面**：以 T2A.6 的真实全景截图为底图，让 GPT 加像素字标题“AI 住进像素办公室”和副标题
  - 输出：1146×717 横版 + 1080×1440 竖版，各 3 个版本
- [ ] **T2B.2 片头 Logo 卡**：像素方块拼出 “Habblaud 中文版”（用于 0:12）
- [ ] **T2B.3 片尾插画**：像素风 GitHub 卡片、Star/Fork 图标，B 站三连图标（点赞、投币、收藏）
- [ ] **T2B.4 贴图包**：标签角标（DeepSeek Harness 蓝、简体中文 青）、键帽 Ctrl/Shift/H、气泡标注底板
  - 提示词：脚本 7.2 节；文字最好后期在剪映里加，不让模型画字
  - 验收：画风与真实截图一致（硬边、无模糊）；没有官方 Logo

### 2C 有声短视频 — 🎬 Grok
- [ ] **T2C.1 片头 4 秒**：用 T2B 的夜景插画做图生视频：窗户灯一盏盏亮、镜头缓慢推近，带环境音
- [ ] **T2C.2 Logo 动画 3 秒**：T2B.2 的 Logo 卡像素块飞入组合 + “叮咚”
- [ ] **T2C.3 片尾 5 秒**：Star/Fork 图标弹出 + 三连图标依次点亮 + 金币声
  - 验收：像素边缘不糊、不变形；不满意就换 Wan 3.0 / Seedance 2.5 / 可灵重做，或者干脆用静态图 + 剪映关键帧
  - 注意：Grok 生成的音效只作参考，最终声音以 2E 为准，避免混音打架

### 2D 配音 — 🎙 Qwen-Audio-3.0-TTS-Plus
- [ ] **T2D.1 主版旁白**：按 T1.1 分镜头逐段生成（一镜一个文件，方便对齐）
- [ ] **T2D.2 竖版旁白**：语速稍快（约 5 字/秒）
  - 读法：Habblaud“哈布劳德”，DeepSeek Harness、GitHub、Star、Fork 按英文读
  - 输出：48kHz WAV
  - 验收：没有读错英文名，没有机器腔

### 2E 配乐与音效 — 🎵 Suno v5 + 🔊 音效库
- [ ] **T2E.1 主版 BGM 2:30**（提示词见脚本 7.3；1:40 处有一段上扬）
- [ ] **T2E.2 竖版 BGM 45 秒**（或从主版截取）
- [ ] **T2E.3 音效包**：走路哒哒、气泡啵、叮、金币、电梯叮咚、翻牌、嗖
  - 验收：保留授权截图（Suno 订阅档、音效许可）

## 阶段 3 · 剪辑合成 — 🙋 你（剪映专业版）

- [ ] **T3.1 粗剪**：按脚本第 3 节摆好录屏和配音，先不加特效
- [ ] **T3.2 精剪**：转场（像素溶解 ≤0.4 秒）、角标、屏幕文字弹出、键帽动画、变速（最多 2 倍）
- [ ] **T3.3 字幕**：剪映识别配音生成字幕，再用 T1.2 校对用词
- [ ] **T3.4 混音**：人声在前，BGM 低 12dB，整体约 -14 LUFS（B 站）
- [ ] **T3.5 打码**：用户名路径、邮箱、余额金额、私人代码
- [ ] **T3.6 竖版**：从主版重新裁成 9:16，按脚本第 4 节重排
  - 输出：`habblaud-main-1080p60.mp4`、`habblaud-short-1080x1920.mp4`

## 阶段 4 · 审片 — 🧠 总控 + 🙋 你

- [ ] **T4.1 AI 审片**：把成片抽帧截图和字幕文件交给多模态模型，对照事实红线和隐私清单检查
- [ ] **T4.2 找人看**：给 1–2 个朋友看，问“30 秒内知道这是干嘛的吗？”“想不想去下载？”
- [ ] **T4.3 改一版**，最终导出

- [ ] **T5.3 GitHub**：README 顶部加视频链接，Release 里附视频 — 🤖 DSH
- [ ] **T5.4 回访**：48 小时后看评论，把功能需求整理成 issue — 🤖 DSH
