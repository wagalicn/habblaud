## 0. 先读：必须遵守的事实红线

这些不是风格建议，做错了会误导观众或违规：

1. **原作者归属**：Habblaud 原作是 **marmottajr/habblaud**（MIT 协议，巴西开发者，界面原文是葡萄牙语）。
   本视频介绍的是 **wagalicn/habblaud 这个 fork** 做的扩展：简体中文 + DeepSeek Harness（DSH）适配。
   片尾和简介必须写明原作者与仓库链接，**不能说成“我做的 Habblaud”**。
2. **不是官方合并**：中文化和 DSH 支持已在上游提了 issue（#253 DSH、#254 中文），**还未被原作者合并**。
   可以说“已向原项目提交”，不能说“官方已支持”。
3. **画面必须是真录屏**：办公室里的小人、状态、工具调用、费用、余额，全部用真实运行录屏。
   **禁止用 AI 生成“假的 Habblaud 界面”**冒充产品画面；AI 生成画面只能用于明显是插画/转场的部分。
4. **不要展示 Habblaud World 联机功能**：World 有“数据真实”条款，DSH 角色目前在 World 里还没有正式映射。
   视频里不提、不演示 World，避免误导。
5. **余额/费用打码**：录屏里的账户余额、费用是真实个人数据，成片中可保留“有这个功能”，但金额建议模糊或用
   自己愿意公开的账号录制。API Key、邮箱、本机用户名路径（如 `C:\Users\xxx`）一律打码。
6. **平台说明照实写**：原 README 写的是 macOS（已测）/ Linux；本 fork 在 **Windows 上实际跑通**过。
   可以说“Windows 也能跑”，不要说“全平台完美支持”。
7. **上线前置条件（给 UP 主本人）**：目前中文化、DSH 适配在 fork 的 `feat/zh-cn-locale`、`feat/dsh-source` 分支；
   终端收起、消息附件、DSH 用量/余额卡片、消息插件等**还只在本地，没推到 GitHub**。
   **发视频前请先把这些合并推送到 fork（建议打一个 Release）**，否则观众 fork 下来没有视频里的功能。

## 2. 视觉与声音规范

### 2.1 风格
- **主视觉：像素风（Pixel Art）**，与 Habblaud 本体一致：等距/俯视办公室、16-bit 色块、硬边、无模糊。
- 转场：像素溶解（dither dissolve）、方块擦除、“电梯门开合”（呼应办公楼）。
- 字幕/标题字体：中文用 **像素字体**（如「Fusion Pixel 缝合像素字体」「方舟像素字体」，均为开源可商用，制作前请再确认授权），
  正文字幕用清晰的黑体（思源黑体），描 2px 深色边。
- 画面比例：主版 1920×1080 / 60fps（录屏 60fps 让小人走路更顺）；竖版 1080×1920。

### 2.2 配色（建议）
| 用途 | 色值 | 说明 |
|---|---|---|
| 背景深色 | `#1B1F3B` | 夜间办公室感 |
| 主强调 | `#4D6BFE` | DeepSeek 蓝，用于 DSH 相关字幕/角标 |
| 辅强调 | `#36C5C0` | 青色，用于“中文化”相关 |
| 警示/等待 | `#FFC94D` | 对应“等你批准”状态 |
| 文字 | `#F5F3E7` | 暖白 |

### 2.3 声音
- BGM：**chiptune / 8-bit 轻快电子**，BPM 110–125；全程 -18 LUFS 左右，压在人声下 12dB。无版权或已授权曲目。
- 音效：小人走路“哒哒”、气泡弹出“啵”、完成任务“叮”、金币“叮铃”、电梯“叮咚”。
- 配音：**年轻、轻快的中文普通话**（男女皆可，推荐偏亲切的女声或活泼男声），语速约 4.5 字/秒。
  TTS 可用，但要调出“讲解感”，不要播音腔。

### 2.4 固定元素
- 左上角角标：`Habblaud 中文版 · fork by wagalicn`（小号像素字，半透明）。
- 讲 DSH 的段落，右上角出蓝色小标签 `DeepSeek Harness`；讲中文化的段落出青色标签 `简体中文`。
